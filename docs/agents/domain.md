# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant architectural decisions under `docs/adr/` when that directory exists.
- If either location is absent, proceed silently.

Use the glossary's defined language for domain concepts and avoid synonyms it explicitly rejects. Surface any conflict with an existing ADR instead of silently overriding it.
